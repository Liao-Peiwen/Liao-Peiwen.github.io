10:T1719,<h1>Yazi のインストールと設定方法</h1>
<p>Yazi は、Rust 製の高速・軽量なターミナルファイルマネージャです。<br>本記事では、Yazi のインストールから設定、プラグイン導入までを順に紹介します。<br>詳細は <a href="https://yazi-rs.github.io/docs/installation">公式ドキュメント</a> を参照してください。</p>

<h2>インストール</h2>
<h3>macOS</h3>
<p>Homebrew を使用して簡単にインストールできます。</p>
<pre><code class="language-bash">brew install yazi
</code></pre>
<h3>Windows</h3>
<p>WinGet または Scoop を利用できます。<br>ここでは WinGet を使用する例を紹介します。</p>
<pre><code class="language-bash">winget install yazi
</code></pre>

<h2>Windows 環境での注意点</h2>
<p>Yazi は内部で MIME タイプを判別するため、Unix 環境の <code>file</code> コマンドに依存しています。<br>Windows では、Git に付属する MSYS2 環境内の <code>file.exe</code> を使用するのが最も簡単です。</p>
<p>また、依存ライブラリ <a href="https://github.com/linebender/resvg">resvg</a> は WinGet に含まれていないため、Scoop で別途インストールする必要があります。</p>
<pre><code class="language-bash">scoop install resvg
</code></pre>
<p>次に、環境変数 <code>YAZI_FILE_ONE</code> に <code>file.exe</code> のパスを設定します。</p>
<pre><code class="language-powershell">[system.Environment]::SetEnvironmentVariable(
  'YAZI_FILE_ONE',
  '&lt;Git_Installed_Directory&gt;\usr\bin\file.exe',
  'Machine' # システム全体 または 'User'（ユーザーレベル）
)
</code></pre>
<p>これにより、画像プレビューなどが正しく動作します。</p>

<h2>シェル関数の設定</h2>
<p>Yazi 起動中にディレクトリを移動しても、終了後にシェルのカレントディレクトリは元に戻ってしまいます。<br>この問題を解消するため、各シェルごとにラッパー関数を定義する方法が推奨されています。</p>
<p>詳しくは以下の公式ドキュメントを参照してください。<br><a href="https://yazi-rs.github.io/docs/quick-start#shell-wrapper">https://yazi-rs.github.io/docs/quick-start#shell-wrapper</a></p>

<h2>設定ファイル</h2>
<p>設定ファイルの保存先は OS によって異なります。</p>
<ul>
<li>Unix 系: <code>~/.config/yazi/</code></li>
<li>Windows: <code>%AppData%\yazi\config\</code></li>
</ul>
<p>Yazi 本体の主な設定ファイルは以下の 3 つです。</p>
<ul>
<li><a href="https://yazi-rs.github.io/docs/configuration/yazi">yazi.toml</a>：基本設定（ファイルオープン動作など）</li>
<li><a href="https://yazi-rs.github.io/docs/configuration/keymap">keymap.toml</a>：キーバインド設定</li>
<li><a href="https://yazi-rs.github.io/docs/configuration/theme">theme.toml</a>：テーマ・配色設定</li>
</ul>
<p>プリセットは <a href="https://github.com/sxyazi/yazi/tree/main/yazi-config/preset">GitHub リポジトリ</a> に公開されています。<br>プリセットを直接編集せず、ユーザー設定で上書きする形が推奨です。</p>
<p>各設定項目の意味は <a href="https://yazi-rs.github.io/docs/term">用語集</a> にまとめられています。</p>

<h2>プラグイン管理</h2>
<p>Yazi には <code>ya pkg</code> というパッケージマネージャが同梱されており、npm のような操作感でプラグインを管理できます。</p>
<pre><code class="language-bash">ya pkg --help
</code></pre>
<p>デフォルトのプラグインディレクトリ：</p>
<ul>
<li>Unix: <code>~/.config/yazi/plugins</code></li>
<li>Windows: <code>%AppData%\yazi\config\plugins\</code></li>
</ul>
<h3>テーマ（Flavors）</h3>
<p>テーマのディレクトリも同様の構造です。</p>
<ul>
<li>Unix: <code>~/.config/yazi/flavors/</code></li>
<li>Windows: <code>%AppData%\yazi\config\flavors\</code></li>
</ul>

<h2>プラグインの設定</h2>
<p>多くのプラグインでは、設定ディレクトリ内に <code>init.lua</code> を作成し、Neovim のような形式で <code>setup</code> 関数を呼び出します。<br>プラグインによっては、ショートカット設定などを TOML ファイルに追加する場合もあります。</p>
<p>参考リンク：</p>
<ul>
<li><a href="https://yazi-rs.github.io/docs/cli">CLI ドキュメント</a></li>
<li><a href="https://yazi-rs.github.io/docs/plugins/overview">プラグイン概要 (BETA)</a></li>
<li><a href="https://yazi-rs.github.io/docs/resources/">プラグイン一覧</a></li>
<li><a href="https://github.com/yazi-rs/plugins">プラグイン集合</a></li>
<li><a href="https://yazi-rs.github.io/docs/flavors/overview">テーマ概要 (BETA)</a></li>
<li><a href="https://github.com/yazi-rs/flavors">テーマ一覧</a></li>
</ul>

<h2>基本操作</h2>
<ul>
<li>コマンドラインで <code>yazi</code> を実行して起動<br>（シェル関数を設定していれば <code>y</code> でも起動可能）</li>
<li>操作体系は Vim に近く、ショートカットの詳細は <a href="https://yazi-rs.github.io/docs/quick-start">Quick Start</a> にまとめられています。</li>
<li><code>q</code>：終了</li>
<li><code>~</code> または <code>F1</code>：ヘルプ表示（主要ショートカット一覧）</li>
</ul>

<h2>まとめ</h2>
<p>Yazi は、シンプルながらも高い拡張性と軽快な操作性を兼ね備えたターミナルファイルマネージャです。<br>Windows / macOS / Linux いずれの環境でも動作し、プラグインやテーマによって柔軟にカスタマイズ可能です。</p>
<p>日常の開発ワークフローを効率化するツールとして、ぜひ一度導入を検討してみてください。</p>
