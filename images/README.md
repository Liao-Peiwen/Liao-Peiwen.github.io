# Images Directory

## Required Images

Please add the following images to this directory:

### Logo Assets

- `logo-icon.png` - Company logo icon (51x47px)
- `logo-text.png` - Company logo text (228x23px)

### Hero Section

- `hero-bg.jpg` - Hero background image (starry sky, 1440x903px minimum)

## Image Sources

You can extract these images from Figma:image.png

1. Open the Figma design
2. Select each image layer
3. Export as PNG (2x for retina displays)
4. Place in this directory

## Temporary Placeholders

Until real images are added, the site will show broken image indicators.
You can use placeholder services like:

- https://placehold.co/
